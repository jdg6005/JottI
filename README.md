# If pulling our changes into a different project
- `Nodes` and `project` directories should be places at the top level
- `provided/Token.java`, `provided/JottParser.java`, `provided/JottTree.java`, and `provided/JottTokenizer.java` should be replaced with our versions
- run the main function in `Main.java`
  - the .jott file name should be provided as the first (and only) command line argument
  - e.g. `phase3testcases/reallyLong.jott`

# If running our project directly w/o changes
- run the main function in `Main.java`
  - the .jott file name should be provided as the first (and only) command line argument
  - e.g. `phase3testcases/reallyLong.jott`
